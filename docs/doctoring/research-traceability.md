# Research and standards traceability

## Exact product decisions supported

- Event-first visibility: GS1 EPCIS defines supply-chain visibility data as events describing what happened to real-world objects and supports status/location/movement/chain-of-custody interoperability. This supports treating source events as evidence inputs, while the core remains vendor-neutral.
- Provenance: W3C PROV-O supplies a stable provenance vocabulary direction for future evidence interoperability; this slice stores an immutable source-record key and locator without claiming full PROV conformance.
- Security/resilience: ISO 28000:2022 covers supply-chain-relevant security management systems; NIST SP 800-161 Rev. 1 Update 1 provides current cybersecurity supply-chain risk-management guidance. These inform future control mapping, not a present compliance claim.

No source above justifies probabilistic disruption weights or recovery optimization parameters, so none are introduced.
